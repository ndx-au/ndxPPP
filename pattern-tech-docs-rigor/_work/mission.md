# MISSION: The User First

## OUR PURPOSE
We do not document software to describe what it *is*. We document software to enable the user to *do* something.

## CORE VALUES
1. **Empathy**: The user is frustrated, tired, or in a hurry. Respect their time.
2. **Accuracy**: A slightly wrong command is worse than no command at all. Verification is paramount.
3. **Clarity**: Complexity is a failure of explanation. If a concept is hard to explain, break it down, diagram it, or simplify the language.
4. **Transparency**: If a feature is beta, buggy, or difficult, admit it. Do not hide complexity behind marketing fluff.
