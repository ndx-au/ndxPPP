# CONSTITUTION: The Style Guide

## 1. VOICE & TONE
- **Active Voice**: "The system generates the log" (Good) vs "The log is generated by the system" (Bad).
- **Direct Address**: Speak to "You" (the user).
- **No Latinisms**: Avoid *i.e.*, *e.g.*, *etc.* Use "for example" or "such as."
- **No Future Tense**: The software exists *now*. "Clicking Save stores the file" (Good) vs "Clicking Save will store the file" (Bad).

## 2. STRUCTURE
- **Headings**: Use sentence case. Do not use gerunds (e.g., use "Install the App" not "Installing the App").
- **Code Blocks**: All code blocks must specify a language syntax highlighter (e.g., `[source,bash]`).
- **Admonitions**: Use `NOTE`, `TIP`, and `WARNING` sparingly. If everything is important, nothing is important.

## 3. PROHIBITED WORDS
- "Please" (Unnecessary clutter)
- "Simply" / "Just" / "Easy" (Condescending to a user who is struggling)
- "Obviously" (Nothing is obvious)
