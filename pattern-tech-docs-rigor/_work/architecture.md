# ARCHITECTURE: The Documentation Tree

## SCOPE

This repository documents **"HyperStream"**, a distributed stream-processing engine.

## DIRECTORY STRUCTURE & SCOPE

### 1. `content/getting-started/`

- **Audience**: Day 0 Users / Evaluators.
- **Goal**: Go from zero to "Hello World" in < 5 minutes.
- **Content Scope**: Installation, Quickstart, Basic Concepts.
- **Exclusions**: Advanced configuration, edge cases.

### 2. `content/guides/`

- **Audience**: Day 2 Operators / Developers.
- **Goal**: Accomplish specific tasks.
- **Content Scope**: "How to Configure TLS," "How to Scale Clusters," "How to Backup Data."
- **Format**: Step-by-step procedures with verified outcomes.

### 3. `content/concepts/`

- **Audience**: Architects / Senior Engineers.
- **Goal**: Deep understanding of internals.
- **Content Scope**: Data consensus algorithms, storage engine design, network topology.
- **Format**: Long-form prose, diagrams.

### 4. `content/reference/`

- **Audience**: Developers / Scripts.
- **Goal**: Lookup specific facts.
- **Content Scope**: API Endpoints, CLI Flag definitions, Error Code dictionary.
- **Format**: Structured data, tables, auto-generated specs.
