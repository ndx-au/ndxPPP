# Project Constitution

## Immutable Rules
- Follow the spec; do not invent new requirements.
- Do not introduce external dependencies unless explicitly allowed.
- Prefer the smallest safe change that satisfies the iteration.
- Keep sensitive data out of logs and docs.

## Quality Bar (Foreman-enforced)
- No failing tests (when tests exist).
- No TODOs left in a “completed” iteration.
- No breaking API changes unless the spec requires it.
